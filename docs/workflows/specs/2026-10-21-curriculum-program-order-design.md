# Curriculum program order — approved design

Academic Core persists custom study-program order in draft and publication rows. Migration 134 adds nonnegative `display_order` with constant default zero, preserving old rows without backfill or trigger changes. Existing ties retain code/ID fallback; UI ordinals are displayed position plus one. Create/copy append under existing edition/level locks. An exact complete-set reorder validates the draft token and level revision, then normalizes actual moves to 1..N atomically. An unchanged effective order is a no-op, including legacy zero ties. Archived rows remain in the workspace set; order changes do not alter their business fields or archived-edit guards.

StudyProgram and StudyProgramOption expose `displayOrder`. PUT `/api/academic/curriculum-levels/{id}/program-order` accepts `ReplaceStudyProgramOrderRequest {draftId,rowVersion,studyProgramIds}` and returns `StudyProgramOrderResult {programs,rowVersion}`. Existing Manage policy, tenant/session boundary and post-commit signal apply. Duplicate IDs reject; incomplete, foreign, stale and concurrent sets conflict. Returned arrays use order/code/ID within their existing edition/level groups across curriculum, delivery and promotion options. No default-plan concept returns.

Publications pin order. Capture uses explicit program columns because the snapshot publication column precedes the new order column. Discard restores order; history fingerprints include order. Migration preserves all pre-existing data, references and current/history divergence. Use normal matched School release selection under maintenance and disposable synthetic tests; no real curriculum writes or live draft edits.

Frontend scope also removes family columns, uses the requested course/hour labels and numeric reporting (one period equals one instructional reporting hour, unchanged number), combines course/activity weekly values within the same grade/term with partial unknowns, keeps annual scope separate, separates editor classifications and moves settings out of the default view. No database metric conversion occurs.
