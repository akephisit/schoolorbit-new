Explicit nonempty scopes retain their coverage, including existing inactive grade IDs. The public API fields and permissions stay unchanged.

It sorts and deduplicates IDs, validates tenant grade existence, and refuses all-grades saves when no active grades exist. The frontend sends empty IDs as all-grades intent and displays the returned concrete snapshot. Curriculum structure preserves only exact existing resource/version/grade/slot tuples when an immutable historical version has empty scope; interactive additions remain invalid. Existing program copying retains pinned versions.
